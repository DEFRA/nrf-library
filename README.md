# nrf-library

Shared library for NRF projects, installable directly from GitHub.

## Installation

Install in a consuming project straight from GitHub — no npm registry needed:

```bash
npm install github:DEFRA/nrf-library              # latest from default branch
npm install github:DEFRA/nrf-library#v0.1.0       # pinned to a release tag
npm install github:DEFRA/nrf-library#main         # track a branch
```

## Consuming from the library

### Javascript modules

```js
import something from '@defra/nrf-library'
```
